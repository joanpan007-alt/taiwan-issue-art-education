# 台灣議題本位藝術與教育平台

以「議題」為入口的台灣藝術實踐案例資料庫，收錄社區藝術、社會參與式藝術、
公共藝術與藝術教育的實踐案例，並附名詞解釋與教學方法。

- **線上網站（GitHub Pages）**：https://joanpan007-alt.github.io/taiwan-issue-art-education/
- **線上平台（真實來源）**：本倉庫為其結構化副本，平台才是唯一真實來源。

## 內容說明
- 案例簡介為 AI 自公開報導改寫、經人工審核，非原文照錄；每則均附原始來源網址。
- 各案例標有查證狀態（已查證／待查證）；部分案例仍在查證中。
- `data/`：結構化資料（案例、名詞、教學方法、系列、篩選、來源字典、介面翻譯字典）。
- `docs/`：GitHub Pages 用的公開版單檔網站。
