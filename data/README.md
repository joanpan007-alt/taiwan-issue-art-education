# data/ — 平台完整結構化資料快照

「台灣議題本位藝術與教育平台」的內容副本，供日後搬遷到獨立網站（如 GitHub Pages）使用。
**線上平台才是唯一真實來源**；本資料夾是副本，抽取自線上版本 `1795358191-f446`（2026-11-22）。

## 檔案

每日「核可後處理」排程維護的核心資料：

| 檔案 | 平台變數 | 內容 |
|---|---|---|
| `cases.json` | `CASES` | 案例（全部欄位） |
| `case_en.json` | `CASE_EN` | 案例英文版 |
| `terms.json` | `TERMS` | 名詞解釋 |
| `terms_en.json` | `TERMS_EN` | 名詞英文版 |
| `methods.json` | `METHODS` | 教學方法（含中英文） |
| `series.json` | `SERIES` | 系列分類（USR／藝術節／長期／短期） |
| `dims.json` | `DIMS` | 篩選維度與選項 |
| `index.json` | — | 抽取時間、平台版本、各項筆數 |

搬遷用、需另外維護的字典（排程未自動更新，於 2026-11-22 手動補入，平台更新後需重抽）：

| 檔案 | 平台變數 | 內容 |
|---|---|---|
| `sources.json` | `S` | 來源字典（標題＋網址） |
| `sources_en.json` | `S_EN` | 來源字典英文標題 |
| `ui_dict.json` | `D` | 全站介面中→英翻譯字典 |

## 未包含
- 深度報導（`STORIES`）：虛構模擬內容、頁面標示「規劃中」，不收入。
- 版面、程式、地圖路徑等呈現層不在此；搬遷時另處理（或直接沿用現有單檔 HTML）。
